<summary><b>🔧 Making the dashboard panels actually "live" (click to expand)</b></summary>

<br/>

GitHub sanitizes README HTML — `<iframe>`, `<script>`, and most CSS animations
are stripped, so a genuinely embedded interactive dashboard isn't possible.
Two practical ways to get close:

1. **Auto-refreshing screenshot (recommended)**
   - Add a small GitHub Action (cron-scheduled, e.g. every 6–12h) that uses a
     headless-browser screenshot service (`playwright`, `puppeteer`, or a free
     API like `htmlcsstoimage.com` / `apiflash.com`) to capture your Looker
     Studio / Streamlit page.
   - Commit the resulting PNG to an `assets/` folder or an orphan branch
     (same pattern as the contribution-snake workflow above).
   - Point the `<img>` tags in the **Live Dashboards** section to that
     committed file — GitHub's CDN will always show the latest commit.

2. **Direct badge links only**
   - Simpler: skip the screenshot and just keep the "Open Live Dashboard"
     badges linking straight to the real Looker Studio / Streamlit Cloud URLs.
     No automation needed, but no in-README preview.

Replace every `#` placeholder link and the `via.placeholder.com` images above
with your real dashboard URLs (and, once set up, your snapshot image paths).
