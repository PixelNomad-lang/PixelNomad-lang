# Hey, I'm Adarsh 👋

I'm a data engineer working at Sun Pharmaceutical Industries, where I build pipelines, dashboards, and the occasional ML model — all in a highly regulated GxP environment. I used to be a full-stack web developer (MERN), and that background still shapes how I think about data systems: **schemas matter, tests matter, and reliability is not optional.**

I care about the full journey — from messy CSVs to production dashboards that people actually trust.

---

## What I do

- **Data Engineering** — Medallion architecture (Bronze/Silver/Gold), ETL/ELT, orchestration (Airflow), cloud warehouses (Snowflake, BigQuery, PostgreSQL).
- **Analytics** — dbt transformations, Looker Studio / Streamlit dashboards, cohort analysis, RFM, business KPIs.
- **Data Science** — Predictive models (scikit-learn), explainability (SHAP), and lately, RAG pipelines with LLMs for document search.

## Some projects I've built

### MechQC — Predictive maintenance for manufacturing
A data warehouse + ML pipeline for QC data. Raw data → cleaned silver tables → gold dashboards → models that flag failure risks.  
[Repo](https://github.com/PixelNomad-lang/MECH-QC-PROJECT) | [Dashboard](https://lookerstudio.google.com/...)

### Logistics DE Pipeline — End-to-end on free tier
Ingest from S3 → transform with dbt → serve from Snowflake, orchestrated with Airflow. Added a RAG layer for natural language queries.  
[Repo](https://github.com/PixelNomad-lang/ai-logistics-data-engineering)

### ChurnIQ — Customer retention analytics
SaaS metrics (MRR, cohorts, RFM) + churn classification + CLV prediction. Built over a weekend, shipped as a Streamlit app.  
[Repo](https://github.com/PixelNomad-lang/ChurnIQ) | [Live App](https://churniq.streamlit.app)

### PharmaQA Auditor — Automated GxP QA checks
Python class that runs ALCOA+ integrity checks, drift analysis, and generates audit reports. Built for a pharma context.  
[Repo](https://github.com/PixelNomad-lang/pharmaqa-auditor)

### Pharma RAG — Ask questions over SOPs
Embed documents, store vectors, retrieve relevant chunks, and answer with an LLM. Handles pharma‑specific terminology.  
[Repo](https://github.com/PixelNomad-lang/pharma-rag)

### SQL Data Warehouse — Medallion reference
A pure‑SQL implementation of bronze/silver/gold layers with tests and documentation.  
[Repo](https://github.com/PixelNomad-lang/sql-data-warehouse-projects)
